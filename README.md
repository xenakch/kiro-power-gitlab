# GitLab Power for Kiro

A community Kiro Power for reviewing GitLab merge requests
and diagnosing CI pipeline failures.

## Status

Under development. The GitLab connection is not configured yet.

## Planned features for version 0.1.0

- Read merge request descriptions and code changes.
- Check pipeline status.
- Inspect failed job logs.
- Summarize findings and suggest fixes.

The first version will use read-only access.

## Approach

Use an existing GitLab MCP server for connectivity and add
focused instructions for review and troubleshooting workflows.

## Installation

Instructions will be added after the first working connection
has been tested.

## Affiliation

This is an independent community project.
It is not an official Kiro or GitLab product.
